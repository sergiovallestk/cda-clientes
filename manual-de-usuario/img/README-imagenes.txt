Coloca aqui (carpeta img/) cada captura de pantalla con el nombre exacto
indicado en el manual (visible en cada recuadro punteado de index.html).

Una vez que esten todas, avisa a Claude para que:
1) cambie USE_REAL_IMAGES = True en build.py, y
2) corra build.py de nuevo para regenerar index.html con las imagenes reales.

No es necesario que edites el HTML a mano.
